# 🎓 Student Personal Organiser

A full‑stack productivity web app designed to help students manage their study time, track progress, and stay motivated – all in one place.

## ✨ Features

- **📅 Smart Study Plan** – Set a daily goal (e.g., 4 hours) and the app splits it across your subjects based on pending tasks and weekly targets.
- **⏱️ Pomodoro Timer** – Customizable focus/break sessions, subject tracking, and background timer (runs even when you switch tabs).
- **✅ Task Manager** – Drag & drop tasks, set priorities, due dates, and filter by completion.
- **📚 Subject Tracker** – Each subject has a colour, weekly target hours, and studied hours (auto‑updated from Pomodoro sessions).
- **📊 Analytics Dashboard** – Visualise study trends, progress bars, and session history.
- **🏆 Gamification** – Streak counter, achievements (10h, 50h, 100h), daily challenge, and weekly subject leaderboard.
- **🤖 Smart Tools** – AI study suggestions, daily reminders, focus music player, and **file uploader** (PDF/txt/md notes – stored locally).
- **🌓 Dark/Light Mode** – Seamless theme switching with persistent preference.
- **🔐 User Authentication** – JWT‑based login/register with email OTP password reset.
- **📱 Responsive** – Works on desktop, tablet, and mobile.

## 🛠️ Tech Stack

- **Frontend:** React (Vite), Framer Motion, Recharts, Axios, React Hot Toast
- **Backend:** Node.js, Express, MongoDB (Mongoose), JWT, Bcrypt, Nodemailer
- **Styling:** Custom CSS with CSS variables (no Tailwind)
